# 도트 디자인 확장 적용 기록

기준: `main`의 `709d2e0`(#54). 첨부 기반 패치를 합치면서 주간 식단 기물과 기존 회의 연결을 유지했다.
기반 및 A~H를 단계별 커밋으로 구분한 통합 PR로 제출한다. 병합·운영 배포는 포함하지 않는다.

## 적용 범위

| 단계 | 적용 내용 |
|---|---|
| 기반 | 공통 `data-px` 부품, 토큰, 장소 그림과 상단 명판 |
| A | 홈과 독립된 사용자별 도트 설정, 문서 루트 테마, 역할·폭·테마·탭 필터 캡처 |
| B | 빈 상태 그림, 알림함 우편함, 검색의 장소 설명 |
| C | 검토 도장·요청자 얼굴·피드백 들여쓰기, 통계와 공통 막대 |
| D | 변경 바인더·기존 이관 기록 얼굴, 프로젝트 테이프 |
| E | 파트원 카드·자리 칩, 활동 로그, 마스터 장식, 실제 자리의 내 책상 |
| F | 본인 책상 서류·새 배정 말풍선, 사무실에서 찾기, 검토에서 회의 열기 |
| G | 하루 한 번 아침 조회와 끄기 설정, 서류 배달, 공통 오늘 할 일 서랍 |
| H | 이미 로딩된 화면 전환, 사무실 로딩 후 사이드바 미니맵 |

`DESIGN.md` §10과 기존 색·테두리·그림자 토큰을 공유한다. 검토 요청자 머리 얼굴은 실제 32px인 `md` 크기를 쓴다.
기존 상태 바·완료 의미·접근성 역할·URL 계약을 유지한다. DB, RLS, `src/data`, 마이그레이션 변경은 없다.
화면 위치 공유와 성과 수치, 도트 글꼴은 추가하지 않았다.

아침 조회는 첫 표시 시 당일 확인을 기록한다. 별도의 당일 숨김 체크 없이 닫기만 해도 하루 1회가 보장되며, 사이드바에서 전체 끄기를 제공한다.
새 업무와 서류 배달은 기존 데이터 갱신과 새 항목 판정을 사용한다. 초기 로딩에는 재생하지 않으며 JS 동작은 reduced-motion을 직접 확인한다.

## 검증 결과

- 타입 검사, 린트, 프로덕션 빌드, `git diff --check` 통과.
- 전체 단위 테스트를 한 번 실행해 발견한 8건(비동기 렌더 시점·콜백 인자·모듈 경계)을 수정하고 해당 파일을 재검증했다. 수정 후 관련 6개 파일 36건 통과, 회의·자리·알림의 추가 검증 21건 통과. 최종 전체 단위 테스트는 PR CI에서 확인한다.
- 전체 preview E2E 34건 통과. 최종 preview **빌드 산출물**에서 설정 독립성·아침 조회·검토 회의/자리 찾기 3건을 재확인해 통과했다.
- 도트/기존 화면 및 1440·1366×657·820·390 폭을 캡처했다. 최종 빌드의 검토요청·계정 관리 16장은 `captures/built-final/`에 있다. 추가 파트원·프로젝트·통계·내 담당 캡처도 `captures/`에 보관한다. 전체 조합의 반복 캡처와 CI 픽셀 비교는 하지 않는다.
- 캡처 스크립트는 기본 전체 조합과 필터, `--compare` 파일 크기·치수 비교를 제공한다. 캡처는 Git에 넣지 않는다.

## 번들

| gzip 바이트 | 변경 전 | 변경 후 |
|---|---:|---:|
| 초기 JS | 150,424 | 153,076 |
| 전체 JS | 327,380 | 341,151 |

초기 상한 150KiB는 유지한다. 전체 상한은 공통 부품·업무 연결·그림·대화창의 지연 로딩 덩어리 추가를 반영해 337KiB로 조정했다.
설정 버튼도 지연 로딩해 Shell 증가를 줄였다. 새 직접 진입점은 번들 검사 목록에 등록했다.

재현 명령:

```sh
npm run typecheck
npm run lint
npm test -- --run
npm run build
npm run test:e2e
git diff --check
npm run capture:screens -- --url http://127.0.0.1:5280 --roles leader --themes pixel,classic --widths 1440,1366,820,390 --tabs reviews,invites --out captures/built-final
```

5280은 로컬 preview 빌드 검수에 사용한 포트이며 실행 환경에 맞게 바꿀 수 있다.
